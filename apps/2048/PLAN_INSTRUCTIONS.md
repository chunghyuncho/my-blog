## 역할
너는 이 프로젝트(my-blog 웹앱 포트폴리오)의 **Plan 담당 서브에이전트**다.
코드를 구현하지 말고, 오직 계획만 작성한다.

## 작업 디렉토리
`C:\Users\15Z90S\Desktop\my-blog` (블로그 프로젝트 루트)

## 사용자 요청
- 2048 게임을 만든다.
- 방향키(↑↓←→)로 숫자 타일을 밀어서 같은 숫자끼리 합치는 퍼즐 게임.
- 점수판(현재 점수, 가능하면 최고 점수)을 포함한다.

## 프로젝트 제약 (CLAUDE.md 기준)
- HTML, CSS, JavaScript만 사용 (프레임워크/빌드도구 금지).
- 앱은 `apps/2048/` 폴더 안에 완전히 독립적으로 구성 (블로그의 다른 파일은 건드리지 않음, 아직 건드리지도 말 것).
- 외부 라이브러리 사용 최소화. CDN은 허용하지만 가급적 직접 구현.
- 모바일에서도 동작해야 한다 (터치 스와이프 등 고려).

## 네가 할 일
1. 게임 설계를 구상한다:
   - 4x4 그리드 데이터 구조와 상태 관리 방식
   - 방향키 입력 처리 및 타일 이동/병합 알고리즘
   - 랜덤 타일 생성 규칙 (2 또는 4 등장 확률 등)
   - 점수 계산 방식
   - 게임 오버 / 승리(2048 타일 등장) 조건과 UI 처리
   - 모바일 터치(스와이프) 입력 지원 방안
   - 반응형 레이아웃 및 시각 디자인(색상, 타일 스타일) 개요
   - 접근성 고려사항 (키보드 포커스, aria-label 등)
2. 파일 구조를 정한다 (예: `apps/2048/index.html`, `apps/2048/style.css`, `apps/2048/script.js` 등).
3. 위 내용을 정리해서 `apps/2048/spec.md` 파일로 저장한다.
   - spec.md에는: 개요, 파일 구조, 핵심 로직 설계, UI/UX, 접근성, 구현 순서 체크리스트를 포함할 것.

## 하지 말아야 할 것
- `apps/2048/` 폴더 밖의 어떤 파일도 만들거나 수정하지 않는다.
- `index.html`, `script.js` 등 실제 구현 코드를 작성하지 않는다 (Plan 단계이므로 spec.md만 작성).
