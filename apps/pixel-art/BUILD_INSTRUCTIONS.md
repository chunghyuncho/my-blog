# Build 서브에이전트 지침 — 픽셀 아트 에디터

## 역할
너는 이 프로젝트(my-blog 웹앱 포트폴리오)의 **Build 담당 서브에이전트**다.
이미 승인된 설계 계획을 그대로 구현한다.

## 작업 디렉토리
`C:\Users\15Z90S\Desktop\my-blog` (블로그 프로젝트 루트)

## 필독 파일
`C:\Users\15Z90S\Desktop\my-blog\apps\pixel-art\spec.md`

이 파일에 개요, 파일 구조, 핵심 로직 설계(격자/드로잉/팔레트/PNG 저장), UI/UX, 접근성, 구현 순서 체크리스트가 모두 정의되어 있다.
**spec.md의 설계와 체크리스트를 그대로 따라 구현하라.** 임의로 설계를 바꾸지 마라 (사소한 구현 디테일은 재량 허용).

## 네가 만들 파일
- `apps/pixel-art/index.html`
- `apps/pixel-art/style.css`
- `apps/pixel-art/script.js`

(spec.md는 이미 존재하므로 건드리지 않는다.)

## 제약 사항 (반드시 지킬 것)
- **`apps/pixel-art/` 폴더 밖의 어떤 파일도 만들거나 수정하지 마라.** 블로그 루트의 `index.html`, `css/`, `js/`, `posts/`, 다른 앱(`apps/2048/`) 등은 이번 단계에서 절대 건드리지 않는다 (Embed는 별도 단계에서 처리됨).
- 프레임워크/빌드 도구 금지. 순수 HTML, CSS, 바닐라 JS만 사용.
- 외부 라이브러리 사용하지 않는다.
- 16x16 격자, 마우스/터치 드래그 드로잉, 색상 팔레트(기본 스와치 + 커스텀 색상), 지우개, 전체 지우기, PNG 저장 기능 모두 반드시 포함.
- 반응형 + 모바일 터치 드로잉 지원 필수 (spec.md 기준).
- 접근성 요구사항 반영 필수 (팔레트/버튼 키보드 조작 가능).

## 완료 후 할 일
1. 세 파일을 모두 작성한다.
2. 브라우저에서 열어 기본 동작(격자에 클릭/드래그로 색칠, 팔레트 색 변경, 지우개, 전체 지우기, PNG 저장 다운로드)을 스스로 한 번 점검한다. 가능하면 로컬 정적 서버로 열어 확인한다.
3. 발견한 이슈가 있으면 직접 수정한다.
4. 완료 보고 시: 구현한 파일 목록, spec.md 대비 달라진 점(있다면 이유 포함), 스스로 확인한 동작 여부를 간단히 요약한다.
