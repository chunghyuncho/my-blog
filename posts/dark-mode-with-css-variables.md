---

다크 모드는 색상 값을 CSS 커스텀 프로퍼티(변수)로 관리하고, `<html>` 태그의 `data-theme` 속성으로 전환하는 방식으로 구현했습니다.

| 토큰 | 라이트 모드 | 다크 모드 |
| --- | --- | --- |
| `--color-bg` | `#ffffff` | `#0d1117` |
| `--color-text` | `#1f2328` | `#e6edf3` |
| `--color-accent` | `#0969da` | `#4da3ff` |

아래는 두 모드의 강조 색상(accent)을 비교한 그림입니다.

![라이트 모드와 다크 모드 색상 토큰 비교](posts/dark-mode-diagram.svg)

페이지를 새로고침할 때 잠깐 잘못된 테마가 보이는 현상(FOUC)을 막기 위해, `<head>`의 스타일시트보다 먼저 실행되는 짧은 인라인 스크립트로 저장된 테마 값을 즉시 적용했습니다.
